What it does

Everything you expect from a modern chat app.

Without an account on someone else's server: messages, files and people all live on one computer on your network.

Channels and DMs

Public and private channels, direct messages and group DMs. Presence, typing, unread counts and drafts that follow you between devices.

Threads, reactions, pins

Reply in a thread without derailing the channel, react with any emoji, pin what everyone needs, and edit or delete your own messages.

Emoji and mentions

A full emoji picker plus autocomplete for :emoji:, @people and #channels. @channel and @here reach everyone.

Files and photos

Upload by button, drag and drop or paste. Images, video and audio show inline, and GPS location is stripped from photos.

Search

Full-text search across the channels and DMs you can see, narrowed with from:, in: and has:image.

Phones and desktops

An installable web app for phones and computers, opt-in push notifications, and a desktop tray app for Windows, macOS and Linux.

Invite by QR code

Sign-up is open for a day after the first start, then closes by itself. After that the admin makes an invite with a role, people scan the QR code, pick a name and they are in.

Admin tools

Settings, roles, an audit log, encrypted backups, certificate management and a reset for starting over.

Alerts

When the network breaks, everyone hears about it.

bubbles is the companion to netdiag. When netdiag sees a printer drop off, an IP conflict or a failed health check, it posts an alert, and everyone on the local network sees it in one channel. Any other tool can do the same.

  1. detectnetdiag noticesThe Brother printer at 192.168.1.50 stops answering.
  2. postWarning alertIt lands in #netdiag-alerts, with a push notification for anyone who opted in.
  3. acknowledgeSomeone is on itOne click shows who took it, so nobody else walks over to the printer.
  4. resolveAll clearnetdiag sends the all-clear and the same alert updates in place.

Three severities

info, warning and critical. Each person chooses which levels notify them, per channel.

One alert, not fifty

A repeat with the same dedupe key updates the existing alert instead of flooding the channel. Optional re-notify for anything left open.

Acknowledge and resolve

People acknowledge in the app; the sender resolves when the problem clears. Each app can only touch its own alerts.

Survives restarts

The Go SDK queues alerts and retries through server restarts and rate limits, so a flapping network does not lose the message.

Integrations

Anything that can call a URL can talk to the LAN.

Four ways in, from a one-line curl to a full two-way bot. Every app gets its own token with only the scopes it needs, and each can be revoked on its own.

Incoming webhooks

A URL per channel. Native JSON alerts, or point anything that posts to Slack at it: text, attachments and blocks work.

REST API and events

Messages, alerts, files and slash commands with a scoped app token, plus a realtime WebSocket event stream for two-way bots.

Go SDK

pkg/bubblesclient finds the server over mDNS, pairs with admin approval and pins the CA. The alert queue retries for you.

MCP for AI agents

Claude and other agents can read channels, search, post messages and raise or resolve alerts through eight MCP tools.

Terminal · post an alert
$ curl --cacert bubbles-ca.pem https://192.168.1.20:28225/hooks/bwh_XXXX \ -H 'Content-Type: application/json' \ -d '{"alert": {"severity": "warning", "title": "Backup is late", "text": "Last success 3 days ago", "dedupe_key": "backup:nas"}}'
ok
$ claude mcp add bubbles -e BUBBLES_CONN="bubbles://192.168.1.20:28225/?token=bub_XXXX&fp=sha256:AB12…" -- bubbles mcp
> Summarise what happened in #netdiag-alerts today and resolve anything that has cleared.

Webhook posts never mention anyone, and every app is rate limited. Full reference: integrations, MCP and OpenAPI.

Security

Real HTTPS on a network with no internet.

Browsers only give a web app notifications, offline mode and camera access over HTTPS. bubbles makes that work on a LAN without a public domain or a cloud service.

  • Its own certificate authority. bubbles creates an ECDSA P-256 CA on first start and issues the server certificate for its IP addresses and bubbles.local.
  • Accounts you control. argon2id passwords, login lockout, secure cookies, and an admin password that is printed only on the server console and saved owner-only on disk.
  • Locked-down web app. A strict Content Security Policy, origin checks, rate limits, and no scripts, fonts or images from anywhere else.
  • Privacy by default. Photo location data is removed, push notifications carry no message text by default, and the server refuses clients from outside private address ranges.
  • Encrypted backups. One command writes an age-encrypted archive; restore it on any host.

Open sign-up, honestly: for the first day anyone on the network can create an account, and any password works. That suits a trusted LAN. Close sign-up, or switch to invites, at any time from the admin settings.

What it does not do: there is no end-to-end encryption. Whoever runs the server can read the messages on it. The full threat model is in docs/security.md.

Reset

Pack up after the LAN party.

bubbles travels. Bring it to a LAN party, a workshop or an event, then wipe it clean for the next one, from the admin Danger zone or the console.

Clear content

bubbles reset --content
  • Every message, thread, reaction and pin
  • All files, pictures and alerts
  • People, channels, apps and settings
  • Everyone stays signed in

Same crew, fresh start: the next session begins with empty channels.

Factory reset

bubbles reset --factory
  • All users, channels, DMs, messages and files
  • Sessions, tokens, apps, webhooks, invites, logs
  • The CA, so trusted devices stay trusted (or rotate it)
  • Server settings, if you choose to keep them

Back to a fresh start: bubbles creates a new admin account with a new password, as if just installed.

Danger zone

Hard to do by accident.

Both resets need the admin password and the instance name typed exactly, show a preview of what will go, and can save an encrypted backup first. Web resets are limited to three tries an hour and written to the audit log; admins can turn them off and keep reset console-only.

  • typed confirmation
  • audited
  • console always works

Tray app

Optional desktop companion: sign in once, get notifications and open bubbles from the tray.

  1. Run bubbles on a computer that stays on. The console prints the address to open and a generated admin password.
  2. Sign in as admin with the printed password and change it. Sign-up is open for a day, so people can already join.
