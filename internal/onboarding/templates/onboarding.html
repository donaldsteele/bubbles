Guest and event Wi-Fi networks often isolate devices from each other ("client isolation"). Then no device can reach this server. Join a network without client isolation, or ask whoever runs the network to turn it off.

{{define "steps"}}
{{if eq .OS "ios"}}
{{else}}
{{end}} iPhone and iPad
  1. Open this page in Safari, tap iPhone / iPad profile and allow the download.
  2. Open Settings → General → VPN & Device Management, tap the downloaded profile and choose Install.
  3. Open Settings → General → About → Certificate Trust Settings and turn on full trust for {{.CAName}}.
{{if eq .OS "android"}}
{{else}}
{{end}} Android
  1. Download the certificate.
  2. Open Settings → Security → Encryption & credentials → Install a certificate → CA certificate. Menu names vary between phones; search Settings for "CA certificate".
  3. Pick bubbles-ca.crt from Downloads and confirm.
{{if eq .OS "windows"}}
{{else}}
{{end}} Windows
  1. Download the certificate.
  2. Double-click bubbles-ca.crt and choose Install Certificate → Current User → Place all certificates in the following store → Trusted Root Certification Authorities.
  3. Or run in PowerShell: Import-Certificate -FilePath "$env:USERPROFILE\Downloads\bubbles-ca.crt" -CertStoreLocation Cert:\CurrentUser\Root
  4. Restart the browser. Edge, Chrome and Firefox use this store.
{{if eq .OS "macos"}}
{{else}}
{{end}} macOS
  1. Download the certificate.
  2. Run in Terminal: security add-trusted-cert -r trustRoot -k ~/Library/Keychains/login.keychain-db ~/Downloads/bubbles-ca.crt
  3. Or double-click it, find it in Keychain Access, open Trust and set When using this certificate to Always Trust.
{{if eq .OS "linux"}}
{{else}}
{{end}} Linux
  1. Download the certificate.
  2. Debian and Ubuntu: sudo cp bubbles-ca.crt /usr/local/share/ca-certificates/ && sudo update-ca-certificates
  3. Fedora, Arch and openSUSE: sudo trust anchor --store bubbles-ca.crt
  4. Chrome and Chromium can also import it under Settings → Privacy and security → Security → Manage certificates.
{{if and (eq .OS "linux") .Firefox}}
{{else}}
{{end}} Firefox on Linux
  1. Firefox on Linux keeps its own certificate list. Open Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import.
  2. Pick bubbles-ca.crt and tick Trust this CA to identify websites.
{{end}}
