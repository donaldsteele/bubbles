bubbles - how to open the server
================================

This is the bubbles chat server. Run it on one computer on your local network,
then open the address it prints from any device on the same network.

Run it
------
  Windows   Unzip, then double-click bubbles.exe (or run it from a terminal).
  macOS     Unzip, then open a Terminal in that folder and run ./bubbles
  Linux     Unzip, then run ./bubbles from a terminal.

The first start prints the admin account and its generated password, plus the
addresses to open (for example https://192.168.1.20:28225 and
https://bubbles.local:28225):

      Sign in as:   admin
      Password:     k7mq-x4pz-9vbd-h2nc

The password is also saved in a file named admin-password.txt in the data
folder (on Windows: %LOCALAPPDATA%\bubbles). Only your user account can read it.
The file is deleted when you change the password.
Keep that console window open while people use the chat.

Unsigned binaries: the release is not code-signed. The operating system will
warn the first time you run it. This is expected.

Windows (SmartScreen)
---------------------
  1. Double-click bubbles.exe.
  2. "Windows protected your PC" appears: click "More info".
  3. Click "Run anyway".

macOS (Gatekeeper)
------------------
  Option A: try to open bubbles once, then go to System Settings >
            Privacy & Security and click "Open Anyway" (macOS 15+).
            On older macOS you can right-click (or Control-click) bubbles
            in Finder, choose Open, then click Open in the dialog.
  Option B: in Terminal, remove the quarantine flag once, then run it:

      xattr -dr com.apple.quarantine ./bubbles
      chmod +x ./bubbles
      ./bubbles

Linux
-----
  Make the file executable once, then run it:

      chmod +x ./bubbles
      ./bubbles

Next steps
----------
  1. Open the address in a browser on the server, sign in as admin with the
     password from the console, and change the password.
  2. Other people: open the onboarding address on the server console (port
     28226, for example http://192.168.1.20:28226), trust the local certificate
     once, then tap "Create your account" (or sign in). On a computer, the
     desktop app can do this for you.
     Sign-up closes by itself after a day. Reopen it in Admin > Settings, or
     ask the admin for an invitation link.

Full documentation (quickstart per OS, certificate install, admin guide,
security notes): see README.md and the docs/ folder of the project.
